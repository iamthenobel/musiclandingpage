# HASHEE — Music Promotion Recreation

This is a responsive React + TypeScript + Vite recreation of the Ditto Music promotion landing page, rebranded as HASHEE with the identifier `#@$#££`. It is a static frontend demonstration: campaign links are safe anchors and do not claim to complete payment or account actions.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`. For a production build, run `npm run build` and then `npm run preview`.

The page includes responsive navigation, campaign feature cards, package selection, testimonial and advice controls, FAQ accordions, scroll reveal motion, reduced-motion support, and the required `/manus-routes.json` route manifest.
